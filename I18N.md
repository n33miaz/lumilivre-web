## F1 — Auto-placement do LocaleSwitcher

### Objetivo
Eliminar a prop manual `placement` em favor de deteccao automatica do melhor lado para abrir o menu, baseado no espaco disponivel no viewport.

### Estado atual
`src/components/ui/LocaleSwitcher.tsx` aceita `placement?: 'top' | 'bottom'` (default `'top'`). Login usa default (abre para cima, button no canto inferior esquerdo). Landing `NavBar` passa `'bottom'` (button no topo).

Limitacao: nao trata posicionamento horizontal. Se o switcher ficar muito a esquerda (Sidebar colapsada = 80px de largura), o dropdown vertical sai da tela.

### Proposta
Refatorar para `placement?: PlacementToken` com:

```ts
type PlacementSide = 'top' | 'bottom' | 'left' | 'right';
type PlacementAlign = 'start' | 'end';
type PlacementToken = 'auto' | `${PlacementSide}-${PlacementAlign}`;
```

Default `'auto'`. As 8 combinacoes nomeadas mapeiam para classes Tailwind:

| Token | Classes |
|---|---|
| `bottom-end` | `top-full right-0 mt-1` |
| `bottom-start` | `top-full left-0 mt-1` |
| `top-end` | `bottom-full right-0 mb-1` |
| `top-start` | `bottom-full left-0 mb-1` |
| `right-start` | `left-full top-0 ml-1` |
| `right-end` | `left-full bottom-0 ml-1` |
| `left-start` | `right-full top-0 mr-1` |
| `left-end` | `right-full bottom-0 mr-1` |

Logica `'auto'`:

```ts
function resolvePlacement(
  buttonEl: HTMLElement,
  menuSize: { width: number; height: number },
  gap = 4,
): PlacementToken {
  const rect = buttonEl.getBoundingClientRect();
  const vw = window.innerWidth;
  const vh = window.innerHeight;

  const fitsBelow = vh - rect.bottom >= menuSize.height + gap;
  const fitsAbove = rect.top >= menuSize.height + gap;
  const fitsRight = vw - rect.right >= menuSize.width + gap;
  const fitsLeft = rect.left >= menuSize.width + gap;

  // Preferencia: vertical primeiro (padrao mais comum), depois flyout horizontal.
  if (fitsBelow) return rect.left + menuSize.width <= vw ? 'bottom-start' : 'bottom-end';
  if (fitsAbove) return rect.left + menuSize.width <= vw ? 'top-start' : 'top-end';
  if (fitsRight) return 'right-start';
  if (fitsLeft) return 'left-start';
  return 'bottom-end'; // fallback
}
```

Re-computa quando:
- `open` muda para `true` (calcula no `useLayoutEffect`).
- `window` resize ou scroll (apenas enquanto `open`).

`menuSize`: medir com `useLayoutEffect` no primeiro render do `<ul>` (via ref) e cachear, OU estimar via constantes (`140` x `36 * LOCALES.length + 8`). Estimativa e suficiente para a primeira versao.

### Tarefas
- [ ] Adicionar `PlacementToken` e `resolvePlacement()` em `src/components/ui/LocaleSwitcher.tsx`.
- [ ] Adicionar estado `resolvedPlacement` e effect que computa em `open` + listeners de `resize`/`scroll`.
- [ ] Mapa de classes (record `PlacementToken -> string`).
- [ ] Atualizar consumers: Login (remover prop, usar default `auto`), `features/landing/NavBar.tsx` (idem).
- [ ] Estender `__tests__/components/ui/LocaleSwitcher.test.tsx`:
  - Mock de `getBoundingClientRect`; verifica que `resolvePlacement` escolhe `top-end` quando botao esta no canto inferior.
  - Verifica que `bottom-end` e escolhido quando ha espaco abaixo.
  - Verifica que `right-start` e escolhido quando o botao esta encostado a esquerda (Sidebar).

### Criterio de aceitacao

### F3.4 — Schemas Zod (validation messages)

Hoje schemas tem mensagens PT-BR hardcoded:
```ts
// src/schemas/studentSchema.ts:4
nomeCompleto: z.string().min(3, 'O nome deve ter no minimo 3 caracteres'),
```

Zod nao tem first-class i18n. Padrao recomendado: converter cada schema em **factory function** que recebe `t`:

```ts
// src/schemas/studentSchema.ts
import type { TFunction } from 'i18next';

export const createStudentSchema = (t: TFunction) => z.object({
  nomeCompleto: z.string().min(3, t('student:validation.name_min_length')),
  matricula: z.string().min(1, t('student:validation.registration_required')),
  // ...
});

export type StudentFormData = z.infer<ReturnType<typeof createStudentSchema>>;
```

Consumer (form) usa:
```ts
const { t } = useTranslation();
const schema = useMemo(() => createStudentSchema(t), [t]);
const form = useForm({ resolver: zodResolver(schema), ... });
```
